# 待测试

- 已同步上游 tigerowo/infinite-canvas 至 v0.8.2 之后的最新提交（RunningHub/ComfyUI 工作流、ComfyUI Bridge、自定传参转译、模型分类、停止生成、再生成方式、局部重绘、批量下载、TokenDance 等）。需执行 `go test ./...` 与前端构建，并回归验证：Sub2API Grok 视频（轮询退避、内容下载）、Canvas OpenAPI 视频、即梦与 MiniMax 海螺、OpenAI 图生图 JSON 格式、Seedream 图生图、视频与画布的停止生成，以及工作流渠道在模型选择器中的显示。
- MiniMax 协议 ID 随上游从 `metaso` 改为 `minimax`，已保存的 `metaso` 渠道不再生效；TokenDance 与 MiniMax 在渠道协议下拉中隐藏。验证后台和本地渠道配置页的协议列表，以及已有渠道的读取。
- OpenAI 渠道新增「图生图格式」选项，本地渠道和后台渠道均可选择「公网图片 URL（JSON）」，按渠道配置生效，不绑定模型名。选择后通过 `/v1/images/edits` 发送 `images: [{ image_url }]`；已有公网图片直链直接复用，本地参考图上传到已配置且可公开读取的对象存储，无法取得公网地址时停止提交并提示。对要求 SSE 的上游需开启现有图片流式设置。请求、存储和流式解析已通过模拟接口测试，实际渠道生成及页面交互仍待人工确认。
- 新增“Canvas OpenAPI（视频）”渠道协议，默认接口地址留空，由管理员或用户自行填写 Base URL；模型使用平台开放模型 UUID。登录用户的模型列表改由后端安全代理拉取，避免浏览器 CORS 拦截；未登录时仍可手动填写 UUID。验证模型拉取、JSON 公网参考素材、FormData 本地图片/视频/音频与首尾帧上传、`task_id` 轮询、`result_url` 成品解析、失败与 `upstream_error` 展示，以及 UUID 仅出现在视频模型选择器中。
- 修复部署构建阻塞：补齐线上已有的通用参数解析函数和测试辅助函数，即梦签名复用包内已有的 SHA-256/HMAC 函数，视频创作页移除对已删除 AutoDL/KIE 模块和专用面板的引用；固定 Docker 启动脚本为 LF 换行。验证容器启动、视频页侧栏/底部布局、提示词提交及普通参考素材上传，并回归即梦签名。
- 「Sub2API（Grok 视频）」已按中转站文档补齐请求与轮询协议：`seconds`/`duration` 和 `aspect_ratio`/`ratio` 成对发送，参考图使用公网 URL 的 `images` 数组；`grok-imagine-video-1.5` 最多 15 秒和 1 张图，`grok-imagine-video` 最多 7 张图。前后端轮询间隔改为至少 6 秒，连续第 5 次 404 才失败，429 尊重 `Retry-After` 并最多重试 5 次，5xx 最多重试 3 次；标准及旧版视频内容地址均可携带渠道 Key 下载。验证未登录直连、登录后本地渠道代理、云端渠道及原 Grok2API 回归。
- 已移植 Gemini、MiniMax H3/海螺、即梦和火山方舟 Seedance/DoubaoVideo 的渠道协议适配；验证即梦签名、图片响应、视频任务提交与轮询，MiniMax H3/海螺的创建与结果解析，以及不同参考素材和时长/分辨率组合。
- 已移除 APIMart、88API、KIE、AutoDL 四种 AI 渠道协议及相关配置、请求转译和创作台功能；验证后台渠道列表不再显示这些协议，现存协议的文本、图片、视频和语音请求不受影响。
- 全站前端更新为极光玻璃视觉风格：验证桌面悬浮导航、移动端导航、首页、画布节点与工具栏、图片/视频工作台、素材与提示词页面、登录页、404 页面及管理后台在浅色和深色主题下的显示与交互。
- 首页轮播已移除 88API 与 Metaso X 内容及对应跳转链接，验证剩余四项轮播显示和切换正常。
- 已删除上游同步带入的站点顶部公告横幅（TokenDance 推广、RunningHub 公告、微信群链接）；验证首页、各工作台和 404 页顶部不再出现公告条，导航位置正常。
- 用户状态操作区已移除 GitHub 按钮及仓库跳转链接，验证桌面导航和画布侧栏不再显示该入口。
- 桌面侧栏首页入口已改用清晰的首页图标，并仅在首页显示选中态；验证不同页面下的图标辨识度和状态切换正确。
- 用户端布局改为左侧栏：桌面端固定侧栏（Agent、我的画布、创作工具、知识库、设置），可收起为图标栏，底部为日夜切换、版本和账号；手机端改为顶部菜单按钮加抽屉；进入单个画布时侧栏隐藏。验证各页面的选中状态、收起展开、手机抽屉，以及画布页全屏不受影响。
- 「创作工具」（生图/视频/工作流）和「知识库」（提示词库/我的素材/素材库）在内容区顶部显示悬浮胶囊切换条，原有路由不变；导航中暂不显示未实现的音乐创作台。验证切换条显示、选中态，以及生图、视频页的原有布局没有被挤压或遮挡。
- 用户端和管理后台背景改为浅灰渐变，卡片改为柔和投影；验证浅色/深色主题下的背景、卡片、弹窗和画布页显示。
- 首页改为 Agent 对话页：支持多轮对话、Markdown 回复、执行轨迹和处理时长、停止生成、复制回复、附件和素材引用、Skill 选择；需要时会调用全局配置的图片/视频/语音模型，结果直接显示在对话里，可引用到输入框、发到画布继续、存入我的素材或下载。验证本地直连和云端渠道下的文字对话、生图、图生图、视频、语音，以及未配置模型时的提示。
- 首页输入框上方新增「对话 / 画布」切换：画布模式沿用原首页行为，新建画布并由画布 Agent 继续；验证带附件和 Skill 的画布模式跳转。
- Agent 会话保存在浏览器本地，侧栏可新建、搜索、重命名、删除会话；页面刷新时进行中的回复会标记为已中断。登录且账号同步可用时，通过 `/api/v1/user-data/agent-sessions` 同步到账号（只同步可见消息和媒体链接，换设备后只带文字历史继续对话）。验证未登录本地保存、登录后合并同步，以及清理本地缓存时不会误删对话里的图片和媒体。
- Agent 对话页补齐细节：输入框上方可直接切换文字模型（写入全局文本模型，画布 Agent 同步生效），显示估算的上下文用量，前 4 个已启用的 Skill 显示为快捷按钮；长对话接近上限或接口报上下文超限时自动压缩较早对话并继续；执行轨迹中显示 Agent 每一步的过程说明；消息显示发送时间，回复支持复制和有帮助/没帮助反馈（反馈目前只记录在会话里）。验证模型切换、长对话压缩、轨迹文字、快捷 Skill 选中/取消和反馈状态的保存与同步。
