# 待测试

- 已移植 Gemini、MiniMax H3/海螺、即梦和火山方舟 Seedance/DoubaoVideo 的渠道协议适配；验证即梦签名、图片响应、视频任务提交与轮询，MiniMax H3/海螺的创建与结果解析，以及不同参考素材和时长/分辨率组合。
- 已移除 APIMart、88API、KIE、AutoDL 四种 AI 渠道协议及相关配置、请求转译和创作台功能；验证后台渠道列表不再显示这些协议，现存协议的文本、图片、视频和语音请求不受影响。
- 全站前端更新为极光玻璃视觉风格：验证桌面悬浮导航、移动端导航、首页、画布节点与工具栏、图片/视频工作台、素材与提示词页面、登录页、404 页面及管理后台在浅色和深色主题下的显示与交互。
- 首页轮播已移除 88API 与 Metaso X 内容及对应跳转链接，验证剩余四项轮播显示和切换正常。
- 用户状态操作区已移除 GitHub 按钮及仓库跳转链接，验证桌面导航和画布侧栏不再显示该入口。
- 桌面侧栏首页入口已改用清晰的首页图标，并仅在首页显示选中态；验证不同页面下的图标辨识度和状态切换正确。
